EXERCISE 01 – SQL LIFE

1. What is SQL?

SQL stands for Structured Query Language.

SQL is a programming language used to communicate with databases. It is mainly used to store, retrieve, update, delete, and manage data.

SQL is commonly used with relational databases such as:

- MySQL
- PostgreSQL
- SQLite
- Microsoft SQL Server
- Oracle Database


2. Why do we use SQL?

SQL is used because databases can contain large amounts of information, and SQL makes it easier to work with that information.

Using SQL, we can:

- Create databases and tables
- Add new data
- Read stored data
- Search for specific data
- Update existing data
- Delete data
- Sort and filter information
- Join information from different tables
- Manage large amounts of structured data


3. Who created SQL?

SQL was developed in the 1970s at IBM.

The main developers were Donald D. Chamberlin and Raymond F. Boyce.

The original language was called SEQUEL, which stood for Structured English Query Language.

It was later renamed SQL.


4. Simple SQL Example

Suppose we have a table called Students.

To display all students:

SELECT * FROM Students;

To find a student named John:

SELECT * FROM Students
WHERE name = 'John';

To add a student:

INSERT INTO Students (name, age)
VALUES ('John', 20);


5. Advantages of SQL

- Easy to learn for basic database operations
- Good for managing structured data
- Can handle large amounts of information
- Supported by many database systems
- Allows fast searching and filtering
- Can combine data from multiple tables
- Widely used in business applications and software development


6. Summary

SQL is a language used to communicate with relational databases.

It allows users and applications to create, read, update, and delete data.

SQL was developed at IBM in the 1970s by Donald D. Chamberlin and Raymond F. Boyce.

Today, SQL is one of the most widely used technologies for working with databases.
